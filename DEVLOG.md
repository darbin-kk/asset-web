# DEVLOG: сайт Ассета (asset-web.ru)

## Контекст
- Назначение: новый сайт студии «Ассет» (IT и автоматизация), домен asset-web.ru. CRM будет на crm.asset-web.ru.
- Стек: Vite, чистый HTML/CSS/JS, three.js (грузится лениво, отдельным файлом), шрифты лежат локально (fontsource).
- Команды: `npm install`, `npm run dev`, `npm run build` (результат в `dist/`), `npm run preview`.
- Где что править: тексты в `index.html`; контакты, адрес формы и Метрика в `src/config.js`; цвета и шрифты стилистик в начале `src/styles.css`; 3D-фигуры в `src/shapes.js`.
- Решения директора (12.11.2026): со старого сайта ничего не берём; услуги только IT и автоматизация; цен нет; портфолио — заглушка; команда не упоминается; в подвале и политике ИП Масасина М. О.; контакты продажника и Метрика — заглушки в config.js; копии базы CRM — на ПК директора.
