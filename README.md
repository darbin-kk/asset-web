# Ассет — сайт, версия 2 (asset-web.ru)

**Это вторая версия сайта студии, собранная с нуля. Со старой версией (ветки `claude/asset-studio-website-4do4w3` и `feature/my-changes`, Vercel) она не связана: общего кода и общей истории нет.** Ветка `v2-asset-web` — отдельная («сиротская»), сливать её со старыми ветками не нужно.

Сайт уже работает: https://asset-web.ru

## Чем отличается от первой версии

| | Версия 1 (старые ветки) | Версия 2 (эта ветка) |
|---|---|---|
| Стек | React + TypeScript + Vite | Vite, чистый HTML/CSS/JS, three.js |
| Хостинг | Vercel | свой сервер в России, nginx |
| Заявки | — | форма → CRM (crm.asset-web.ru) + Telegram |
| Содержание | прежнее | только IT и автоматизация, без цен |

## Запуск

```
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

## Где что лежит

- `src/shared.html` — все тексты: знак, главное меню, разделы (главная, услуги, процесс, работы, новый проект), подвал, нижняя панель для телефона. Общий для всех адресов.
- `index.html`, `uslugi/`, `process/`, `raboty/`, `kontakty/` — у каждого раздела свой адрес; в файле только title, описание и canonical. Разметку подставляет `vite.config.js` (метки `<!--@head-->` и `<!--@body-->` → `src/head.html` и `src/shared.html`).
- `404.html` — страница «Такой страницы нет» (в nginx: `error_page 404 /404.html`).
- `policy.html` — политика обработки персональных данных.
- `src/config.js` — контакты продажника, адрес формы, номер Метрики. Пустое значение = блок не показывается.
- `src/styles.css` — стилистики (Ассет, ресторан, производство, магазин, услуги) через CSS-переменные.
- `src/scene.js`, `src/shapes.js` — 3D-сцена из частиц; грузится лениво и только там, где потянет устройство.
- `public/` — иконка, картинка превью `og.jpg`, robots.txt, sitemap.xml.
- `deploy/` — всё серверное: настройки nginx, служба приёма заявок `lead.py`.
- `DEVLOG.md` — журнал: решения, история изменений, что не сделано. **Начинать читать с него.**

## Выкладка

Сайт — статические файлы. После `npm run build` содержимое `dist/` копируется на сервер в `/var/www/asset-web`. Автовыкладки нет. Секретов в репозитории нет: токен бота и секрет CRM лежат на сервере в `/etc/asset-lead.env`.

## Что осталось сделать

1. Вписать контакты продажника в `src/config.js`.
2. Подключить Яндекс Метрику (нужен номер счётчика, заготовка в `src/main.js`).
3. Наполнить портфолио (сейчас заглушка на вкладке «Работы»).
4. Замерить скорость на реальном телефоне (в лаборатории 82 из 100, на ПК 100).
5. Перенести DNS домена к провайдеру (сейчас DNS на том же сервере).

Задачи ведутся в MBOX, проект «Сайт Ассета» (#664, #665).
